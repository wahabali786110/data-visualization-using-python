# Data Visualization using Python 📊

This repository tracks my progress and hands on practice in mastering data visualization techniques using Python. It serves as a practical foundation for analyzing datasets, discovering patterns, and building the intuition necessary for Data Science and Machine Learning.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** * `Matplotlib` - For foundational, highly customizable static plots.
  * `Seaborn` - For attractive, statistical data visualizations.
  * `Plotly` - For creating interactive, publication-quality graphs.

## Repository Structure
The repository is organized by library, making it easy to navigate through different visualization tools and techniques:

* `/Matplotlib` — Foundational plotting techniques (line charts, bar graphs, scatter plots, etc.).
* `/Seaborn` — Statistical visualizations (heatmaps, violin plots, pair plots, etc.). *(Coming Soon)*
* `/Plotly` — Interactive dashboards and complex charts. *(Coming Soon)*
